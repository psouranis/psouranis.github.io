Markov's, Chebyshev's, Hoeffding's and Jensen's inequalities

This post is focused in outlining some of the most well known and used inequalities (particularly in statistics).

Markov’s Inequality

Theorem 1. (Markov's inequality). Let \(X\) be a non-negative random variable and suppose that \(\mathbb{E}(X)\) exists. For any \(t>0\), $$ \mathbb{P}(X > t) \leq \dfrac{\mathbb{E}(X)}{t}. $$


PROOF. Since (X > 0),

\[\mathbb{E}(X) = \int_{0}^{+\infty} x f(x) dx = \int_{0}^{t} x f(x) dx + \int_{t}^{+\infty} x f(x) dx \ge \int_{t}^{+\infty} x f(x) dx \ge t \int_{t}^{+\infty} f(x) dx = t \mathbb{P}(X > t). \quad {\tiny \blacksquare}\]


Chebyshev’s Inequality

Theorem 2. (Chebyshev's inequality). Let \(\mu = \mathbb{E}(X)\) and \(\sigma^{2} = \mathbb{V}(X)\). Then, $$ \mathbb{P}(|X - \mu | \ge t) \leq \dfrac{\sigma^2}{t^2} \text{ and } \mathbb{P}(|Z| \geq k) \leq \dfrac{1}{k^2}. $$ where \(Z = (X - \mu) / \sigma\). In particular, \(\mathbb{P}(|Z| > 2) \leq 1/4\) and \(\mathbb{P}(|Z| > 3) \leq 1/9\).


PROOF. We use Markov’s inequality to conclude that

\[\mathbb{P}(|X - \mu | \geq t) = \mathbb{P}(|X - \mu |^2 \geq t^2) \leq \dfrac{\mathbb{E}(X- \mu)^2}{t^2} = \dfrac{\sigma ^2}{t^2}. \quad {\tiny \blacksquare}\]

This inequality generally provides a poor bound compared to what might be deduced if more aspects are known about the distribution involved but in any case it provides a useful easy to calculate bound.

Hoeffding’s Inequality

Theorem 3. (Hoeffding's inequality). Let \(Y_1, \ldots, Y_n\) be independent observations such that \(\mathbb{E}(Y_i) = 0\) and \(a_i \leq Y_i \leq b_i\). Let \(\epsilon > 0\). Then, for any \(t > 0\), $$ \mathbb{P}\bigg(\sum_{i=1}^{n} Y_i \geq \epsilon \bigg) \leq e^{-t\epsilon}\prod_{i=1}^{n} e^{t^{2}(b_i - a_i)^2 / 8}. $$


PROOF. For any (t > 0), we have, from Markov’s inequality, that

\[\begin{split} \mathbb{P}\bigg(\sum_{i=1}^{n}Y_i \geq \epsilon\bigg) &= \mathbb{P}\bigg(t\sum_{i=1}^{n}Y_i \geq t\epsilon\bigg) = \mathbb{P}\bigg(e^{t\sum_{i=1}^{n}Y_i} \geq e^{t\epsilon}\bigg) \\ &\leq e^{-t\epsilon} \mathbb{E}\big(e^{t\sum_{i=1}^{n}Y_i}\big) = e^{-t\epsilon} \prod_{i=1}^{n} \mathbb{E}(e^{tY_i}). \end{split}\]

Since \(a_i \leq Y_i \leq b_i\), we can write \(Y_i\) as a convex combination of \(a_i\) and \(b_i\), namely \(Y_i = \alpha b_i + (1 - \alpha)a_i\) where \(\alpha = (Y_i - a_i) / (b_i - a_i)\). So, by the convexity of \(e^{ty}\) we have

\[e^{tY_i} \leq \dfrac{Y_i - a_i}{b_i - a_i}e^{tb_i} + \dfrac{b_i - Y_i}{b_i - a_i} e^{ta_i}.\]

Take expectation of both sides and use the fact that \(\mathbb{E}(Y_i)=0\) to get

\[\mathbb{E}(e^{tY_i}) \leq - \dfrac{a_i}{b_i - a_i} e^{tb_i} + \dfrac{b_i}{b_i - a_i} e^{ta_i} = e^{g(u)}\]

where \(u = t(b_i - a_i), g(u)=-\gamma u + \log(1 - \gamma + \gamma e^u)\) and \(\gamma = -a_i / (b_i - a_i)\). Note that \(g(0) = g'(0) = 0\). Also, \(g''(u) \leq 1/4\) for all \(u>0\). By Taylor’s theorem, there is a \(\xi \in (0, u)\), such that

\[\begin{split} g(u) &= g(0) + ug'(0) + \dfrac{u^2}{2} g''(\xi)\\ &= \dfrac{u^2}{2} g''(\xi) \leq \dfrac{u^2}{8} = \dfrac{t^2(b_i - a_i)^2}{8}. \end{split}\]

Hence,

\[\mathbb{E}(e^{tY_i}) \leq e^{g(u)} \leq e^{t^2(b_i - a_i)^2 / 8}. \quad {\tiny \blacksquare}\]

Jensen’s Inequality

Theorem 4. (Jensen's inequality). If \(g\) is convex, then $$ \mathbb{E}\big(g(X)\big) \geq g\big(\mathbb{E}(X)\big). $$ If \(g\) is concave, then $$ \mathbb{E}\big(g(X)\big) \leq g\big(\mathbb{E}(X)\big) $$


PROOF. Let \(L(x) = a + bx\) be a line, tangent to \(g(x)\) at the point \(\mathbb{E}(X)\). Since \(g\) is convex, it lies above the line \(L(x)\). So,

\[\mathbb{E}\big(g(X)\big) \geq \mathbb{E}\big(L(X)\big) = \mathbb{E}(a + bX) = a + b\mathbb{E}(X) = L\big(\mathbb{E}(X)\big) = g\big(\mathbb{E}(X)\big). \quad {\tiny \blacksquare}\]

From Jensen’s inequality we see that \(\mathbb{E}(X^2) \geq \big(\mathbb{E}(X)\big)^2\) and if \(X\) is positive, then \(\mathbb{E}(1 / X) \geq 1 / \mathbb{E}(X)\). Since \(\log\) is concave, \(\mathbb{E}\big(\log (X)\big) \leq \log\big(\mathbb{E}(X)\big)\).

The above inequalities and their respective proofs have been taken from [1].
